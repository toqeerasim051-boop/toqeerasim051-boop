## ⭐ Featured Project: TripWise

**[TripWise](https://github.com/toqeerasim051-boop/tripwise) · [Live Demo](https://tripwise-phi-ten.vercel.app)**

A travel planner built with **React 18, Vite and Tailwind CSS**. Explore ~250 countries, save a wishlist, plan trips day by day, track a budget and download the plan as a PDF.

- REST API integration (REST Countries, Open-Meteo weather) with caching and offline fallback
- Itinerary builder with auto-planning and rainy-day warnings, plus a budget calculator with a spending forecast
- Interactive attractions map (Leaflet), light/dark themes, and a mobile-first, accessible UI
- 579 automated tests with Vitest and React Testing Library
